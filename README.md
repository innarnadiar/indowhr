# Analisis "Indonesia's World Happiness Report"
Analisis skor kebahagiaan Indonesia berdasarkan World Happiness Report (WHR) 2021–2025, disusun oleh Innar Nadiar (23 September 2026).

# Ringkasan Temuan
Skor kebahagiaan Indonesia naik dari 2021 ke 2025 dan mendekati rata-rata global secara nilai, tapi ranking dunia Indonesia tetap di sepertiga bawah (WHR 2025: peringkat 83 dari 147 negara).
Posisi Indonesia stagnan relatif dibanding negara ASEAN lain dan negara ber-GDP setara, negara lain naik dengan laju yang sama atau lebih cepat.
Ada gap antara kebahagiaan subjektif dan kondisi ekonomi riil: skor subjektif naik, sementara kelas menengah menyusut 9,5 juta orang (2019–2024) dan skor kesejahteraan finansial jadi aspek terlemah dalam Indeks Kualitas Hidup Indonesia (ISS, 2025).
